
# Student Mobile Portal

A student portal project for practicing Git and GitHub collaboration.

## Student Profile Component

The StudentProfile component displays a student's name,
student ID, and academic program using fictional sample data.

### Component File

- `StudentProfile.jsx`

### Information Displayed

- Name
- Student ID
- Program


## Integration Example

In an initialized React application, import the component
into a parent component:

    import StudentProfile from "./StudentProfile";

Then render it inside the parent component:

    <StudentProfile />

Note: This example shows how the component can be
integrated into a React application. The current
repository is a standalone exercise.
